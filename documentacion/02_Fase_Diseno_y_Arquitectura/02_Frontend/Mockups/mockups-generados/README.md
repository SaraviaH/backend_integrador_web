## 📋 Reglas de Versionado

1. **Pantallas Aprobadas Únicamente:** Solo se almacenan aquí las versiones finales aprobadas por el usuario. Descartar intentos o iteraciones fallidas de la IA.
2. **Formatos Admitidos:** Imágenes `.png`, `.jpg`, `.webp` o vectores `.svg`.
3. **Mapeo a Componentes:** Cada captura servirá de referencia visual directa para el diseño atómico de componentes en `02_Frontend/ARCHITECTURE.md` y para la especificación de los sprints de UI en Fase 03.
