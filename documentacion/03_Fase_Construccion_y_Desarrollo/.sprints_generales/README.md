# Sprints Generales del Sistema (Transversales)

> **Propósito:** Carpeta que aloja las especificaciones (`SPEC.md`) de aquellos sprints que abarcan **capacidades transversales a todo el software**, las cuales no pertenecen exclusivamente ni al Frontend ni al Backend.
